# Targeted Impressions Skills

Git proves what merged. We prove what went live: each change we call shipped is matched to the commit the served page itself reports, then followed to the crawler that fetched it and the search results it earned.

Open agent skills for that practice: receipts over claims. Merged is not shipped; served is not used.

## What a skill is

A skill is a plain markdown recipe. Each file starts with frontmatter that has a `name` and a `description` that begins with **Use this when…**. The body is the procedure an agent (or a person) follows.

Nothing here is a product, a score, or a claim about traffic. It is a recipe you can point an agent at.

## How to use one

1. Pick a skill under `skills/<slug>/SKILL.md`.
2. Give that file (or its path) to any agent that can follow markdown instructions.
3. Keep the skill's holds: read-only skills stay read-only; gates that require an explicit YES still require one.
4. Prefer live probes over memory. If a check cannot be measured, say so.

Works with any agent that can read a file and call tools. No special runtime is required.
